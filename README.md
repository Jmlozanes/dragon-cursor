# Snake Game

A simple Snake Game built using HTML, CSS, and JavaScript. The game allows players to control the snake, collect food, increase their score, and avoid hitting the boundaries.

## Features

- Snake movement using keyboard arrow keys
- Food generation system
- Score tracking
- Game over condition
- Simple and responsive game interface

## Technologies Used

- HTML
- CSS
- JavaScript
- HTML Canvas API

## How to Play

1. Use the arrow keys to control the snake.
2. Eat the red food to increase your score.
3. Avoid hitting the game boundaries.
4. Try to achieve the highest score possible.
